# 1 ในยุทธภพ — จำลองชีวิตมูริม

เกมจำลองชีวิตในโลกมูริม (ยุทธภพ) และโลกเทพเซียน แนว "1 in 8 Billion" — เกิดแบบสุ่ม ใช้ชีวิตทีละปี เลือกเส้นทาง และดูว่าชีวิตนี้จะจบอย่างไร

เล่นได้ทันทีในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร ทั้งเกมอยู่ในไฟล์ `index.html` ไฟล์เดียว

## ฟีเจอร์หลัก
- สองโลก: ยุทธภพ และโลกเทพเซียน (ขึ้นไปถึงโลกเทพได้)
- สำนักฝ่ายธรรมะ · อธรรม · มาร, ตระกูลใหญ่, ทายาทผู้นำ
- ระบบ (System) 10 ประเภท พร้อมเควส เควสหลัก และเควสลับ
- ผู้ข้ามมิติพร้อมของติดตัวจากต่างโลก
- กระเป๋า / ถุงมิติ, มิติลับ, งานประมูล, อาชีพเซียน, ถ้ำบ่มเพาะ, ปิดด่าน
- ศัตรูคู่แค้น, แผนที่, ดวลด้วยวิชาจริง, ชะตาประจำวัน, โหมดท้าทาย
- สุสานบรรพชน, สารานุกรม, สถิติ, อัลบั้มความทรงจำ, การ์ดชีวิต
- เซฟอัตโนมัติในเครื่อง (localStorage) 3 ช่อง

## รันในเครื่อง
เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย

## Deploy บน Vercel
1. ไปที่ https://vercel.com/new แล้ว Import repository นี้
2. Framework Preset: **Other** · ไม่ต้องตั้ง Build Command · Output Directory เว้นว่าง
3. กด Deploy

ทุกครั้งที่ push ขึ้น `main` Vercel จะ deploy ใหม่ให้อัตโนมัติ
