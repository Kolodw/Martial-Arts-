# 1 ใน นวนิยาย — จำลองชีวิตยุทธภพและเทพเซียน

เกมจำลองชีวิตในโลกมูริม (ยุทธภพ) และโลกเทพเซียน แนว "1 in 8 Billion" — เกิดแบบสุ่ม ใช้ชีวิตทีละปี เลือกเส้นทาง และดูว่าชีวิตนี้จะจบอย่างไร

เล่นได้ทันทีในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร ทั้งเกมอยู่ในไฟล์ `index.html` ไฟล์เดียว

## ฟีเจอร์หลัก
- สองโลก: ยุทธภพ และโลกเทพเซียน (ขึ้นไปถึงโลกเทพได้)
- สำนักฝ่ายธรรมะ · อธรรม · มาร, ตระกูลใหญ่, ทายาทผู้นำ
- ระบบ (System) 10 ประเภท พร้อมเควส เควสหลัก และเควสลับ
- ผู้ข้ามมิติพร้อมของติดตัวจากต่างโลก
- กระเป๋า / ถุงมิติ, มิติลับ, งานประมูล, อาชีพเซียน, ถ้ำบ่มเพาะ, ปิดด่าน
- ศัตรูคู่แค้น, แผนที่, ดวลด้วยวิชาจริง, ชะตาประจำวัน, โหมดท้าทาย
- สุสานบรรพชน, สารานุกรม, สถิติ, อัลบั้มความทรงจำ, การ์ดชีวิต
- สร้างตัวละครเองด้วยแต้ม · ชุดสวมใส่ · บันทึกเควส · ตัวเลือกย่อไว้ได้ เวลาเดินเป็นเดือน
- งานช่าง (ปรุงยา ตีเหล็ก ค่ายกล ยันต์) · เมืองและภารกิจเมือง · ดันเจี้ยน 7 แห่ง · ผู้คนและคู่หู · ครัวเรือนและพงศาวดาร
- เสียงบรรยากาศตามฉากและอากาศ · คู่มือ (`/wiki`) · ย้ายเซฟข้ามเครื่องด้วยรหัส
- เซฟอัตโนมัติในเครื่อง (localStorage) 3 ช่อง

## รันในเครื่อง
เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย

## Deploy บน Vercel
1. ไปที่ https://vercel.com/new แล้ว Import repository นี้
2. Framework Preset: **Other** · ไม่ต้องตั้ง Build Command · Output Directory เว้นว่าง
3. กด Deploy

ทุกครั้งที่ push ขึ้น `main` Vercel จะ deploy ใหม่ให้อัตโนมัติ

## ระบบออนไลน์ (แชทโลก · ทำเนียบ · ประลองเงา · ฝากเซฟ)
โค้ดฝั่งเซิร์ฟเวอร์อยู่ที่ `api/online.js` (Vercel Function) ใช้ฐานข้อมูล Upstash Redis
1. เปิดโปรเจกต์ใน Vercel → แท็บ **Storage** → **Create Database / Browse Marketplace** → เลือก **Upstash for Redis** (แพ็กเกจฟรีได้) → เชื่อมกับโปรเจกต์นี้
2. Vercel จะเพิ่มตัวแปร `KV_REST_API_URL` และ `KV_REST_API_TOKEN` ให้เอง (หรือตั้ง `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` เองก็ได้)
3. กด Redeploy — ปุ่ม 🌐 ออนไลน์ ในเกมจะใช้งานได้ทันที

ถ้ายังไม่ได้เชื่อมฐานข้อมูล เกมเล่นได้ปกติ เพียงแต่ระบบออนไลน์จะขึ้นว่ายังเชื่อมต่อไม่ได้
