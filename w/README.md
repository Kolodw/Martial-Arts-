# /w — ไฟล์โลกที่แยกออกจาก app.js

แต่ละโลกที่ย้ายออกมาอยู่ที่ `/w/<ชื่อ>.js` และโหลดด้วย `wLoad('<ชื่อ>')` / `wNeed('<ชื่อ>', fn)` (ดู BLOCK 117 ใน app.js)

กฎ
- ไฟล์โลกต้องจบด้วย `wReady('<ชื่อ>')`
- โค้ดใหม่ของโลกที่ย้ายมาแล้ว เขียนในไฟล์นี้เท่านั้น ห้ามต่อท้าย app.js
- ทุกที่ที่เข้าโลก (เริ่มชีวิต, โหลดเซฟ, ดูคนอื่นเล่น) ต้องผ่าน `wNeed` ก่อน
- แผนที่ไฟล์: `node tools/split-map.mjs > /tmp/map.json && node tools/split-report.mjs /tmp/map.json` (ต้องมี acorn, acorn-walk)
