# /w — ไฟล์โลกที่แยกออกจาก app.js

แต่ละโลกที่ย้ายออกมาอยู่ที่ `/w/<ชื่อ>.js` และโหลดด้วย `wLoad('<ชื่อ>')` / `wNeed('<ชื่อ>', fn)` (ดู BLOCK 117 ใน app.js)

กฎ
- ไฟล์โลกต้องจบด้วย `wReady('<ชื่อ>')`
- โค้ดใหม่ของโลกที่ย้ายมาแล้ว เขียนในไฟล์นี้เท่านั้น ห้ามต่อท้าย app.js
- ทุกที่ที่เข้าโลก (เริ่มชีวิต, โหลดเซฟ, ดูคนอื่นเล่น) ต้องผ่าน `wNeed` ก่อน
- แผนที่ไฟล์: `node tools/split-map.mjs > /tmp/map.json && node tools/split-report.mjs /tmp/map.json` (ต้องมี acorn, acorn-walk)

## โลกที่ย้ายแล้ว
- `sky.js` 🌠 ทะลุฟ้าดารา — โค้ดใหม่ของโลกนี้เพิ่มในไฟล์นี้ (เดิมที่ app.js ก่อน `window._sky={...}` ตอนนี้อยู่ในท่อน sky1 ของ w/sky.js)
- `mw.js` 🏙️ ระบบโลกย่อยยุคปัจจุบัน (window._wld…_wld33 ฯลฯ) — บล็อกใหม่ที่ต่อยอด window._wld* ให้เขียนในไฟล์นี้ (ต่อท้ายก่อน `wReady('mw')`) ถ้าเขียนใน app.js ตอนโหลด window._wld จะยังไม่มี
- `mwb.js` 🏙️ หน้าเกิด/ออกแบบตัวละคร/วัยเด็กยุคปัจจุบัน (window._lifeTbl, mwBornPage, mwBStart …) — โหลดก่อน mw.js
- `en.js` 🌐 พจนานุกรมอังกฤษก้อนใหญ่ (คำแปลใหม่ยังใส่ใน app.js ได้ตามเดิม)
- `upd.js` 📜 บันทึกอัปเดตรุ่นเก่า (รุ่นใหม่ยังเพิ่มหัว CHANGELOG ใน app.js ตามเดิม)
- `fate.js` 🌱 ชะตาไม่เป็นเส้นตรง (ทุกโลก): เมล็ดชะตาซ่อน · ชาติก่อนตามมาทวง · พงศาวดารทั้งเว็บ (`?a=chr`) · ข่าวลือจริง/เท็จ · จบโดยไม่ตาย · บทส่งท้าย 30 ปี · เส้นเรื่องพลิกประจำโลก — โหลดหลังเปิดเกม (BLOCK 119 ใน app.js ส่ง `fs` ไปกับ life)
- `meta.js` 🧭 ระบบรอบตัวเกม (ทุกโลก): 🏯 สำนักของผู้เล่นจริง (`?a=gd` อ่าน / `gdw` เขียน) · 👋 ระหว่างที่คุณไม่อยู่ + ของขวัญกลับมา · 🎯 เป้าหมายร่วมทั้งเว็บ (ใน `?a=chr` → `cg`/`pcg`) · 📲 ติดตั้งแอป · 🧭 ชีวิตหน้าลองอะไรดี · 🖼️ การ์ดเรื่องสั้น — โหลดหลังเปิดเกม (BLOCK 122 ใน app.js)
- `nsys.js` 📱 ผู้ได้รับระบบ (โลกยุคปัจจุบันแบบปกติ): เครื่องยนต์เควส/สอบเลื่อนขั้น/มินิเกม/ตอนจบ — โหลดต่อจาก mw.js · ข้อมูล 22 ระบบอยู่ใน `nsys1.js`–`nsys5.js` (push เข้า window._NSD · nsys5 = เบียว + ประตูหน้ากระดาษ ที่มีแถบที่สอง)
- `rift.js` 🌀 ระบบรอยแยก เฟส 1 (ทุกโลก): ข้ามโลก 3 แบบ (ทั้งตัว/วิญญาณเข้าร่าง/คนจากโลกอื่นมาหา) · คู่โลก ปัจจุบัน→ยุทธภพ, ซอมบี้→ยุทธภพ, ฮันเตอร์→วิญญาณยุทธ์, ยุทธภพ→ปัจจุบัน(เดิม), คนปี 2054→ปัจจุบัน, คนยุคปัจจุบัน→ยุทธภพ · ความแปลกถิ่น · สมอ · ประตูเปิดอีกครั้ง · สถานะ S.rift / S.rvis · สมุด LS murim_rift — โหลดหลังเปิดเกม (BLOCK 123 ใน app.js)
